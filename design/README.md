# Wali's design portfolio

Live at https://inanewali.github.io/portfolio/design/

## Adding work images

Drop images into `images/` with these exact names and they appear automatically:

- `images/ideate.png` — gym busyness concept (sketches, wireframes, or a prototype)
- `images/hive.png` — Hive screens
- `images/auditedge.png` — AuditEdge screens
- `images/solar-car.png` — Solar Car Team graphics

Until an image exists, that project shows as text only, so the site never looks broken.
Wide images (about 1600×1000) look best.
